Remote Networking

Mobile Access via Tailscale in 60 Seconds

Connect your iPhone or Android phone to your home server from coffee shops or cellular networks without public port forwarding.

1️⃣

Install Tailscale

Download the Tailscale client on your Windows PC and on your smartphone. Log in with the same account to join your private mesh.

2️⃣

Configure Firewall

Run our single PowerShell firewall rule so Windows Defender allows incoming packets across the Tailscale interface.

3️⃣

Connect from Mobile

Open your mobile browser and enter your PC's Tailscale IP (e.g. http://100.85.12.34/) to manage your server anywhere.

PowerShell (Administrator) — Allow Tailscale Mesh Subnet 
New-NetFirewallRule -Name "Ownbase-Tailscale-Inbound" `
    -DisplayName "Ownbase Tailscale Remote Access" `
    -Direction Inbound `
    -Protocol TCP `
    -LocalPort 80, 443, 3000, 3001, 8080 `
    -RemoteAddress 100.64.0.0/10 `
    -Action Allow `
    -Profile Any
